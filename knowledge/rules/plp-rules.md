# PLP rules

- Build only CORE and DISCOVERY campaigns in MVP.
- Use one campaign per listing.
- Use one ad group per model, including inside family and Discovery listings.
- Generate model-product, make-model-product, and optional year-make-model-product keywords.
- Do not generate `for` as a standalone word in PLP keywords.
- Use Phrase match for keywords without a year.
- Use Exact match for each keyword generated with a model year.
- Core campaigns negate other fitment model terms.
- Discovery campaigns negate Core models so Discovery does not compete for deliberate Core traffic.
