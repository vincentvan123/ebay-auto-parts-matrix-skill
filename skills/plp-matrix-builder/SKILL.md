# PLP Matrix Builder

1. Create one campaign per listing with deterministic names.
2. Create one ad group per compatibility model.
3. Generate model, make-model, `for` phrase, and configured year terms.
4. Negate competing Core/model intents according to project rules.
5. Deduplicate keywords case-insensitively within each ad group.
6. Export PLP rows and negative-keyword rows separately.
